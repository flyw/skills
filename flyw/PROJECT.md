# 项目说明 (PROJECT.md)

## 1. 项目定位
基于 Antigravity 插件架构的领域知识与协作契约管理工具包 (`flyw`)。

## 2. 核心功能与架构
通过插件内包含的一系列自主 Agent Skill，实现从需求澄清、架构规划、防幻觉护栏到规则/需求自动同步的全流程智能化辅助。

## 3. 项目技能清单 (Skills List)

1. **`blueprint`**
   - **说明**：代码编写与重构前的结构化对齐与规划工具。在修改代码前强制进行上下文审查与范围对齐，并选择合适的规划工具。
   - **应用场景**：编写新代码、重构、架构变更或建立结构化开发流程。

2. **`cognitive-grounding-guard`**
   - **说明**：元认知诚实与防幻觉护栏。在高风险任务中校验置信度阈值，防止模型产生幻觉。
   - **应用场景**：高风险代码生成、事实性查询或关键架构决策。

3. **`double-blind-circuit-breaker`**
   - **说明**：双盲熔断机制。当用户输入模糊（如代词不清、缺乏上下文）且模型置信度较低时主动挂起并澄清。
   - **应用场景**：面对不确定提示词或高幻觉风险时的主动澄清。

4. **`human-in-the-loop-feedback`**
   - **说明**：人机协同反馈。支持专家级用户干预、中间步骤检查与会话记忆修正。
   - **应用场景**：用户对之前错误提出反馈或要求精细控制 Agent 推理过程。

5. **`output-presentation-formatter`**
   - **说明**：结构化输出格式化工具。优化 Agent 输出呈现方式以降低人类认知负荷。
   - **应用场景**：格式化复杂技术解答、多步骤教程、代码审查或对比分析。

6. **`pattern-composition`**
   - **说明**：设计模式选择与架构组合工具。评估并组合软件设计模式，维护“深度模块”与干净的隔离接缝。
   - **应用场景**：设计新模块、重构复杂代码或建立组件架构。

7. **`project-ideation-alignment`**
   - **说明**：项目启动前的领域知识映射与意图显性化。在探索不熟悉领域时厘清概念并建立执行蓝图。
   - **应用场景**：探索新业务领域、想法未成熟或需要严格定义执行边界时。

8. **`query-intent-alignment`**
   - **说明**：查询意图主动对齐。当人类输入缺乏约束或环境上下文时，主动展开澄清。
   - **应用场景**：Prompt 缺乏约束、上下文缺失或边界不清晰时。

9. **`sync-project-summary`**
   - **说明**：工作契约与项目描述同步工具。从对话上下文中自动提取信息，维护 `./GEMINI.md`（工作契约，单次上限2条）与 `./PROJECT.md`（项目需求与架构）。
   - **应用场景**：用户请求总结、更新或同步项目规则、工作方式或项目上下文。
