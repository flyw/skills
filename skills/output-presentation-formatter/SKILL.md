# Output Presentation Formatter

Bridge the **Gulf of Evaluation**. Structure responses for scannability and low cognitive load.

## Process

### 1. Structure Hierarchy
- **TL;DR First**: Lead with a 1-2 sentence core conclusion.
- **Scannable Layout**: Group comparison data into Markdown tables; isolate runnable code into language-tagged blocks.

### 2. Audience Calibration
- **Expert**: Strip conversational filler. Present dense technical facts, signatures, and diffs.
- **Beginner**: Use intuitive analogies and progressive disclosure. Limit paragraphs to 3 sentences.

> **Completion Criterion**: Output leads with a TL;DR summary and strictly matches the target user expertise layout.
